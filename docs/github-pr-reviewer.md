# GitHub PR Reviewer

## Overview
This is an exported n8n workflow for **GitHub PR Reviewer**.

## Nodes Included
- **GitHub Webhook** (n8n-nodes-base.githubWebhook)
- **OpenAI** (n8n-nodes-base.openAi)
- **GitHub Comment** (n8n-nodes-base.github)

## Setup Instructions
1. Import this workflow into your n8n instance.
2. Review the nodes and configure necessary credentials.
3. Activate the workflow.
